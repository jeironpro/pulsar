Formato abierto de datos · v1.0 · Licencia MIT

Datos jerárquicos,
legibles a primera vista.

PULSAR (.psr) es un formato de datos estructurados que se lee como prosa: bloques con ->, atributos con >>, listas con |. Sin llaves anidadas ni indentación traicionera.

Probar en el playground Ver en GitHub
pip install pulsar-psr
desliza

01 · El formato

Tres símbolos y ya lo entiendes.

Todo el lenguaje cabe en una línea: los bloques se abren y se cierran de forma explícita, y cada atributo declara su valor sin ambigüedad.

  • -> nombreInicia un bloque con nombre; puede contener atributos y otros bloques.
  • <-Cierra el bloque más reciente.
  • clave >> valorAtributo del bloque actual, con tipos nativos inferidos.
  • a | b | cLista en línea.
  • { k >> v }Objeto inline.
  • :: notaComentario hasta fin de línea.
  • << … >>Texto multilínea literal.

03 · Características

          
Pequeño por fuera, completo por dentro.

        


        

          

            
Parser en tres fases

            
Lexer → AST → builder. Cada error reporta línea y columna exactas — nunca tracebacks crípticos.

            PSRLexError: Línea 4 col 12: operador incompleto
          

          

            
Validador de esquemas

            
Esquemas en JSON o en el propio .psr: tipos, obligatorios, hijos esperados y modo estricto opt-in.

          

          

            
Round-trip fiel

            
Serializa y re-parsea sin corromper tipos: "42" sigue siendo texto, no un número disfrazado.

          

          

            
CLI psr

            
parse, dump y validate disponibles desde el primer pip install.

          

          

            
Docker oficial

            
Imagen multi-stage publicada en GHCR, con el CLI como entrypoint.

            ghcr.io/jeironpro/pulsar
          

          

            
Cero dependencias

            
Solo biblioteca estándar de Python: instala en cualquier entorno sin resolver conflictos. El paquete completo pesa menos que este párrafo comprimido en gzip… casi.

06 · Casos de uso

          
Donde PULSAR late mejor.

        


        

          

            

              
01
Configuración de aplicaciones

              
Bloques anidados para entornos y límites, sin depender de la suerte con la indentación.


-> entorno produccion
    debug >> false
    limites >> { rpm >> 500 }
<-

            

            

              
02
Datasets legibles

              
Registros uno tras otro, diff-friendly y revisables en pull requests sin dolor.


-> sensor
    id >> th-01
    lecturas >> 21.4 | 21.7 | 22.1
<-

            

            

              
03
Esquemas validados

              
Tipos y campos obligatorios verificados antes de que el dato llegue a producción.


:: esquema.psr
-> usuario
    nombre >> str
    edad >> int
<-

            

            

              
04
Enseñanza

              
Tres símbolos para explicar estructuras de datos, árboles y recursión sin ruido sintáctico.


-> nodo
    valor >> 7
    -> hijo
        valor >> 3
    <-
<-

08 · FAQ

          
Preguntas frecuentes.

        


        

          

            ¿Por qué otro formato de datos más?
            
JSON prioriza a las máquinas y YAML/TOML nacieron para configuración. PULSAR optimiza la lectura humana de datos jerárquicos: tres símbolos, bloques con cierre explícito y cero ambigüedad por indentación.

          

          

            ¿Reemplaza a JSON?
            
No busca reemplazarlo sino convivir: psr parse emite JSON cuando lo necesitas y el validador acepta esquemas escritos en JSON.

          

          

            ¿Cómo funcionan los esquemas?
            
Un esquema declara el tipo del bloque, sus atributos (tipo y obligatoriedad) e hijos esperados. Con "estricto": true además rechaza atributos no declarados.

          

          

            ¿Qué pasa si mi archivo tiene errores?
            
El parser reporta la línea y columna del problema («bloque sin cerrar», «operador incompleto», «nombre inválido») en lugar de un stack trace ilegible.

          

          

            ¿Hay imagen de Docker oficial?
            
Sí: ghcr.io/jeironpro/pulsar. Imagen multi-stage (~50 MB) con el CLI como entrypoint; monta tu directorio de trabajo en /data.

          

          

            ¿Cómo contribuyo?
            
Lee CONTRIBUTING.md: issues etiquetados como idea, PRs con pruebas y CI verde en Python 3.10–3.14.
